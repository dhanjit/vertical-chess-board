# monolith + bearing — the ringing-tolerant pairing

The **`monolith`** artwork on the **`bearing`** pivot. Mechanically this is
[`../familiar_bearing/`](../familiar_bearing/) — same MR63ZZ pressed into the
piece's back, same hub/dowel/cap as `pin`, same shopping list, same assembly,
same timed flip test — applied to the small austere set. Read that README for
everything procedural; only two things differ here:

- **This is the pairing that shrugs off the bearing's open problem.** The
  bearing's unmeasured cost is *ringing* after a flip, and a swinging piece
  eats sweep clearance. The monolith set has **11.67 mm** of worst-pair margin
  against familiar's 1.25 mm — so if Phase 0 shows long ring-down and no
  damper retrofit fully fixes it, `monolith + bearing` is the combination that
  still works: parks ≈0° at any μ *and* has room to swing while it settles.
- **Small pieces, relatively bigger steel.** The ~0.5 g bearing rides at the
  pivot of bodies weighing 2.2–4.5 g — proportionally a bigger bite out of the
  pendulum lever than on the familiar set. Parking stays ≈0° regardless; what
  it slows is settling, which is the thing the flip test times anyway.
